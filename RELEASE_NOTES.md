## Install

```
pip install pypdfcraft            # Windows / macOS / Linux / Android wheels on PyPI
pip install "pypdfcraft[ocr]"     # + OCR models
```
Termux / Pydroid users: download the `linux_aarch64` (or `linux_armv7l`) wheel from the assets below and
`pip install` the file. Verify downloads with `SHA256SUMS.txt`.

Engine: PdfCraft (Rust) - see CHANGELOG.md for what changed.
